# Метод БАЙ — пакет для запуска MVP через Codex

Это стартовый технический пакет для превращения локального HTML-прототипа в онлайн-сервис с аккаунтами учениц и преподавательской панелью.

## Технологии
- Next.js App Router + TypeScript
- Tailwind CSS + shadcn/ui
- PostgreSQL + Prisma
- Email/password authentication
- Русский интерфейс
- Все записи ученицы изолируются по `userId`
- Бренд: шоколадный `#3B2A24`, оливковый `#6E7B52`, бежевый `#EADCCB`, белый `#FFFFFF`; без золотого цвета

## Важно
Пакет — спецификация для разработки, а не готовый развернутый сервис. Перед публичным запуском нужны проверка безопасности, тестирование, настройка резервного копирования и политика обработки персональных данных.

## Как начать в ChatGPT Codex
1. Создайте приватный репозиторий GitHub, например `metod-bai-platform`.
2. Загрузите в корень репозитория содержимое этого архива.
3. Подключите репозиторий в Codex в ChatGPT.
4. Откройте `docs/MASTER_PROMPT_START.md` и передайте его Codex.
5. Выполняйте задачи строго по одной из `docs/TASKS_FOR_CODEX_MVP.md`.
6. После каждой задачи просите Codex запустить доступные проверки и исправить ошибки до перехода дальше.

## Исходный прототип
Локальный HTML-прототип кабинета следует использовать как референс логики и визуального направления, но не переносить его как готовую серверную архитектуру.
