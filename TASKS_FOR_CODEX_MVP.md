# Задачи Codex — выполнять строго по одной

## TASK 1 — Каркас проекта
Создай Next.js App Router + TypeScript проект с Tailwind CSS и shadcn/ui. Настрой русский язык, базовый layout и дизайн-токены Метод БАЙ. Добавь страницы-заглушки: `/`, `/login`, `/register`, `/dashboard`. Добавь README с командами. Запусти lint/typecheck/build. Пока не реализуй бизнес-логику.

## TASK 2 — База данных и Prisma
Настрой Prisma и PostgreSQL по `prisma/schema.prisma`. Добавь миграцию и безопасный seed для локальной разработки. Проверь связи и ограничения. Не добавляй реальные персональные данные.

## TASK 3 — Аутентификация и роли
Реализуй email/password auth через поддерживаемую библиотеку. Безопасный хеш пароля, серверная сессия, вход/выход, защита маршрутов. Роли STUDENT, TEACHER, ADMIN. Не позволять пользователю самостоятельно назначить себе роль преподавателя или администратора. Добавь тесты доступа.

## TASK 4 — Кабинет ученицы
Сделай адаптивный dashboard: статус стартовой диагностики, прогресс 12 недель, быстрые переходы к карте, задачам и дневнику. Показывай пустые состояния и понятные подсказки.

## TASK 5 — Стартовая диагностика
Реализуй форму 20 оценочных и 10 открытых вопросов. Проверяй шкалу 1–5 и длины текстов. Сохраняй ответы на сервере для текущего пользователя. Добавь черновик/предупреждение при уходе со страницы, если это уместно. Не называй результат психологическим диагнозом.

## TASK 6 — Генерация карты
Реализуй серверную функцию расчёта шести направлений на основании спецификации в PRD. Сохраняй снимок результата. Покажи интерпретации как гипотезы, сильные опоры, направления внимания, основу бренда и первые действия. Для барьеров объясни, что высокий балл означает более частое проявление препятствий. Добавь unit-тесты расчёта.

## TASK 7 — План на 12 недель
Создай экран недельного плана, задачи, статусы, даты/заметки и прогресс. Предусмотри seed-шаблон задач, который можно редактировать без изменения кода. Не делай выполнение задания доказательством коммерческого успеха.

## TASK 8 — Дневник «БАЙ. Моя опора»
Реализуй ежедневную запись одного действия/качества, которое ученица ценит в себе, и еженедельную запись трёх побед. Пользователь может просматривать только собственные записи. Добавь пустое состояние и редактирование/удаление.

## TASK 9 — Финальная диагностика и сравнение
Разреши финальную диагностику как отдельный снимок. Покажи старт/финал по направлениям и разницу значений, открытые ответы и фактические действия отдельно. Не делать выводов о причинности или клинических изменениях.

## TASK 10 — Панель преподавателя и безопасность
Список назначенных учениц, прогресс и статусы. Серверные проверки, что преподаватель имеет связь с ученицей. Добавь тесты на горизонтальный доступ: студент не читает чужое, преподаватель не читает неназначенных, студент не повышает роль. Добавь экспорт/печать, обработку ошибок, удаление аккаунта/экспорт данных и финальный аудит перед деплоем.

## Правило работы
После каждой задачи: показать изменённые файлы, запустить проверки, исправить ошибки, дать короткий отчёт и остановиться. Не переходить к следующей задаче без подтверждения пользователя.
